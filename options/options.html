yt-dlp bridge

Checking…

One-click YouTube, DASH and split-audio HLS downloads by running a locally installed yt-dlp (+ ffmpeg) through Chrome's native messaging. Nothing leaves your machine.

Install / repair the bridge
  1. Install the tools (Windows): winget install yt-dlp.yt-dlp Gyan.FFmpeg OpenJS.NodeJS.LTS
  2. From the ComboBreaker source folder, register the host for this extension ID (…): …
  3. Fully quit and relaunch the browser, then hit ↻ above.

macOS / Linux: ./native/install.sh <extension-id>. Remove with native/uninstall.ps1. Details in native/README.md.

Cookies let yt-dlp fetch age-gated or members-only videos; Chrome must be fully closed for yt-dlp to read its cookie DB on Windows.

    Request headers

    Modify outgoing requests to this site. Useful for User-Agent, Accept-Language, Authorization, custom debug headers, etc.

    Response headers

    Modify response headers as the browser receives them. Useful for loosening Content-Security-Policy, X-Frame-Options, or stripping Set-Cookie on third-party iframes.

    Powered by Chrome's declarativeNetRequest. Rules apply to all requests where the destination domain is —. Save to apply.
