ComboBreaker

One-time setup for YouTube downloads

Downloading from YouTube (and a few other sites) needs a small program on your computer. It runs yt-dlp for the extension. Nothing is sent anywhere except to the video site itself, exactly as if you were watching it.

Checking…

  1. Copy the setup command

  2. Paste it into Terminal and press Return

    It downloads about 250 MB (a private copy of Node, Python, yt-dlp and ffmpeg) into your user folder. Nothing else on your computer is changed.

  3. Come back here

    This page turns green on its own when the Helper is ready. Then just click any download badge.

All set

Close this tab and click the download badge on any video. Downloads land in ~/Downloads/combobreaker.

Change the folder or default quality in ComboBreaker options.

If YouTube asks you to “sign in to confirm you’re not a bot”

Some networks trip YouTube’s bot check. Turn on Use my browser’s cookies in ComboBreaker options › Downloads and try again: the download then looks like your own browser session. Use this with an account you would not mind YouTube frowning at; heavy downloading on a signed-in account has occasionally led to warnings.

What gets installed, and how to remove it

Everything lives in one folder:

  • a private copy of Node.js (runs the bridge script that talks to the extension)
  • a private copy of Python with yt-dlp (does the actual downloading, updates itself)
  • a static ffmpeg build (joins video and audio, makes MP3s)
  • one small registration file so your browser knows where the Helper is

Remove it any time by running .

Manual install (developers)

From a checkout of the repo, with this extension id :

./native/install.sh

Add --browsers chrome,brave,edge to register for several browsers. On Windows run native\install.cmd <id>.
